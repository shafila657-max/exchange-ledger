# Exchange Ledger — Prototype

Clickable prototype of a SAR → AED → INR currency-exchange ledger for a single operator:
deals with bulk-rate slabs, transit batches converted and settled in parts, party ledgers,
capital, debtors and creditors.

- Single static page: `index.html` (no build step).
- Sample data only. Each visitor's data is stored in their own browser (localStorage).
- Record-keeping prototype — it does not move money.
